# StudioSpace – Creative Studio Booking Platform

StudioSpace is a full-stack studio booking platform designed to connect creative professionals with spaces tailored to their production needs. Users can explore, discover, and book creative spaces such as photography studios, sound stages, podcast rooms, music suites, and art workshops.

The platform provides an intuitive browsing experience with category-based filtering, location and price filters, ratings, and sorting options. Authenticated users can also list their own studio spaces, manage existing listings, edit studio information, and keep track of their bookings.

### Key Features
- **Studio Discovery:** Browse creative spaces across multiple categories.
- **Advanced Filtering:** Filter studios by category, location, price, and rating.
- **Studio Details:** View images, descriptions, amenities, host information, and reviews.
- **User Authentication:** Secure authentication using Better Auth and JWT.
- **Studio Management:** Add, edit, view, and manage personal studio listings.
- **Booking Management:** Create bookings, view reservations, and access booking receipts.
- **Responsive Design:** Interface designed for desktop, tablet, and mobile devices.
- **Dynamic Data:** Studio and booking information managed through a MongoDB database.

### Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Better Auth, JWT
- **Deployment:** Vercel

StudioSpace aims to simplify the process of finding and managing creative spaces by bringing studio discovery, listing management, and booking functionality together in one platform.
